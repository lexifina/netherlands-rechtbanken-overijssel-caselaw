1
De procedure

1.1

Het verloop van de procedure blijkt uit:

- de dagvaarding- de conclusie van antwoord tevens eis in reconventie- de conclusie van repliek in conventie tevens antwoord in reconventie- de conclusie van dupliek in conventie tevens repliek in reconventie,

- waarna Code 95 niet meer heeft gereageerd.

1.2

Ten slotte is vonnis bepaald.

2
De feiten

2.1

Code 95 heeft in de periode van april 2023 t/m juli 2023 voor rekening van gedaagde voor diverse leerlingen van [gedaagde] rijlessen, toetsen en praktijkexamens voor de opleidingen vrachtwagen C en vrachtwagen met aanhangwagen (CE) verzorgd.

2.2

Voor deze werkzaamheden zijn facturen gestuurd naar [gedaagde] . Deze facturen zijn tot op heden onbetaald gebleven.

3
Het geschil

3.1

Code 95 vordert – samengevat – veroordeling van [gedaagde] tot betaling van de openstaande facturen die zij aan [gedaagde] heeft verzonden in verband met de door Code 95 verzorgde vrachtwagenrijopleidingen voor verschillende leerlingen van [gedaagde] . Volgens Code 95 zijn deze facturen ondanks herhaalde verzoeken onbetaald gebleven. Het totaalbedrag van de vordering uit hoofde van deze facturen bedraagt € 5.429,86.

3.2

[gedaagde] voert verweer. Zij stelt dat de afspraken waarop Code 95 haar vordering baseert, zijn gemaakt met de voormalig compagnon, de heer [naam] . Volgens [gedaagde] is sinds 4 december 2024 de heer [bestuurder]  enig aandeelhouder en bestuurder van [gedaagde] B.V. [bestuurder] voert aan dat tussen partijen nooit een formele samenwerkingsovereenkomst tot stand is gekomen. Daarnaast stelt hij dat Code 95 fouten heeft gemaakt bij het verzenden van de facturen en de communicatie daarover. Volgens [gedaagde] zijn deze fouten aan Code 95 toe te rekenen, zodat de daaruit voortvloeiende incassokosten en proceskosten voor rekening van Code 95 dienen te blijven. Tot slot stelt [gedaagde] een tegenvordering op Code 95 te hebben van twee facturen, ten bedrage van in totaal € 1.125,00.

3.3

Bij repliek voert Code 95 aan dat de interne wijzigingen aan de zijde van [gedaagde] geen invloed hebben op de onderhavige vordering. Volgens Code 95 is [bestuurder] bovendien wel degelijk bekend met de tussen partijen gemaakte afspraken. Daarnaast stelt Code 95 dat de aanmaningen niet per post, maar per e-mail zijn verzonden. Voor zover [bestuurder] aanvoert dat deze e-mails niet zijn ontvangen omdat zij zijn verzonden naar het privé-e-mailadres van de voormalig compagnon, komt deze omstandigheid volgens Code 95 voor rekening en risico van [gedaagde] en kan deze haar niet worden tegengeworpen. Ten slotte betwist Code 95 de door [gedaagde] gestelde tegenvordering tot verrekening van twee facturen. Volgens Code 95 zijn deze facturen door een geheel andere entiteit gestuurd, te weten Vrachtwagen Opleidingen te Rijswijk, verzonden. Om die reden komen deze facturen volgens Code 95 niet voor verrekening met de onderhavige vordering in aanmerking.

3.4

Bij dupliek handhaaft [gedaagde] haar verweer en voert zij aan dat Code 95 onvoldoende heeft onderbouwd dat tussen partijen een overeenkomst tot stand is gekomen. Volgens [gedaagde] kan uit de door Code 95 overgelegde facturen niet worden afgeleid dat daadwerkelijk een overeenkomst is gesloten, nu een factuur een eenzijdig opgesteld document is en op zichzelf geen bewijs vormt van de daaraan ten grondslag liggende afspraken. Daarnaast betwist [gedaagde] dat het uitblijven van een reactie op de aanmaningen voor haar rekening dient te komen. Volgens [gedaagde] had Code 95 eenvoudig de juiste contactgegevens kunnen achterhalen door de website van [gedaagde] te raadplegen, waarop het correcte zakelijke e-mailadres vermeld staat. Nu Code 95 dit heeft nagelaten, kunnen de gevolgen daarvan volgens [gedaagde] niet op haar worden afgewenteld. [gedaagde] verzoekt de kantonrechter dan ook de vorderingen van Code 95 integraal af te wijzen.

3.5

Op de stellingen van partijen wordt hierna, voor zover nodig, nader ingegaan.

4
De beoordeling

4.1

Kern van het geschil is de vraag of tussen partijen een overeenkomst tot stand is gekomen op grond waarvan [gedaagde] gehouden is de door Code 95 verzonden facturen voor de verzorgde vrachtwagenrijopleidingen te voldoen. De kantonrechter beantwoordt deze vraag bevestigend en overweegt daartoe als volgt.

4.2

Op grond van artikel 6:217 van het Burgerlijk Wetboek komt een overeenkomst tot stand door een aanbod en de aanvaarding daarvan. De wet stelt daarbij als uitgangspunt geen vormvereisten aan het sluiten van een overeenkomst. Dat betekent dat een overeenkomst niet schriftelijk behoeft te worden vastgelegd, maar ook mondeling of stilzwijgend tot stand kan komen. Het ontbreken van een schriftelijke samenwerkingsovereenkomst brengt daarom niet zonder meer mee dat geen overeenkomst tussen partijen bestaat.

4.3

Code 95 heeft aan haar vordering ten grondslag gelegd dat zij in opdracht van [gedaagde] vrachtwagenrijopleidingen heeft verzorgd voor verschillende leerlingen. Ter onderbouwing daarvan heeft zij de desbetreffende facturen overgelegd, waarin de verrichte opleidingen zijn gespecificeerd. Daarnaast heeft zij gesteld dat deze werkzaamheden daadwerkelijk zijn uitgevoerd en dat de facturen ondanks herhaalde aanmaningen onbetaald zijn gebleven. Daarmee heeft Code 95 haar stellingen voldoende feitelijk onderbouwd.

4.4

Van [gedaagde] mocht vervolgens worden verwacht dat zij deze stellingen gemotiveerd zou weerspreken. Dat heeft zij echter nagelaten. [gedaagde] heeft zich in hoofdzaak beperkt tot de stelling dat geen formele samenwerkingsovereenkomst bestaat en dat de afspraken zijn gemaakt met de voormalig compagnon, de heer [naam] . Een dergelijke betwisting is, gelet op de door Code 95 overgelegde stukken en haar toelichting, onvoldoende. Daarbij is van belang dat [gedaagde] niet concreet heeft betwist dat de betreffende leerlingen daadwerkelijk de door Code 95 verzorgde opleidingen hebben gevolgd. Evenmin heeft zij toegelicht dat deze opleidingen zonder haar opdracht of medeweten zijn verzorgd of dat de facturen betrekking hebben op andere werkzaamheden dan door Code 95 is gesteld. Ook heeft [gedaagde] geen stukken overgelegd waaruit blijkt dat de facturen inhoudelijk onjuist zijn of dat de daarop vermelde prestaties niet zijn verricht. Onder deze omstandigheden kan niet worden volstaan met een algemene ontkenning van het bestaan van een overeenkomst.

4.5

Voor zover [gedaagde] heeft aangevoerd dat de afspraken uitsluitend zijn gemaakt met de voormalig compagnon, de heer [naam] , leidt dat niet tot een ander oordeel. Indien [naam] destijds namens [gedaagde] opdrachten aan Code 95 heeft verstrekt, zijn de daaruit voortvloeiende rechten en verplichtingen aan [gedaagde] toe te rekenen. Dat nadien een wijziging heeft plaatsgevonden in de aandeelhouders- en/of bestuursstructuur van [gedaagde] , waarbij [bestuurder] enig aandeelhouder en bestuurder is geworden, doet aan reeds namens de vennootschap aangegane verplichtingen niet af. Interne wijzigingen binnen een rechtspersoon kunnen immers niet aan een contractuele wederpartij worden tegengeworpen.

4.6

Ook het verweer dat de aanmaningen naar een onjuist e-mailadres zijn verzonden, kan [gedaagde] niet baten. Nog daargelaten dat Code 95 heeft gesteld dat de aanmaningen zijn verzonden naar het e-mailadres dat bij haar bekend was, raakt dit verweer uitsluitend de wijze waarop Code 95 betaling heeft gevorderd en niet het bestaan van de onderliggende betalingsverplichting. Als [gedaagde] haar interne communicatie of contactgegevens niet tijdig heeft aangepast na het vertrek van de voormalig compagnon, komt dat in beginsel voor haar eigen rekening en risico. Bovendien heeft [gedaagde] niet gesteld dat zij de facturen zelf nooit heeft ontvangen, maar uitsluitend dat de aanmaningen niet op het juiste e-mailadres zijn binnengekomen. Dat is onvoldoende om de verschuldigdheid van de facturen aan te tasten.

De eis in reconventie van [gedaagde]

4.7

Het beroep van [gedaagde] op verrekening slaagt evenmin. Code 95 heeft gemotiveerd betwist dat de door [gedaagde] genoemde facturen geen betrekking hebben op een rechtsverhouding tussen partijen. Volgens Code 95 zijn deze facturen immers afkomstig van een andere rechtspersoon, te weten Vrachtwagen Opleidingen te Rijswijk. [gedaagde] heeft deze betwisting niet nader met stukken of een inhoudelijke toelichting weersproken. Daarmee heeft zij onvoldoende onderbouwd dat sprake is van een opeisbare tegenvordering op Code 95 die voor verrekening in aanmerking komt. Het beroep op verrekening wordt daarom verworpen.

4.8

Gelet op het voorgaande is de kantonrechter van oordeel dat voldoende is komen vast te staan dat tussen partijen een overeenkomst tot stand is gekomen, op grond waarvan Code 95 de betreffende vrachtwagenrijopleidingen heeft verzorgd. De daarvoor verzonden facturen vinden hun grondslag in die overeenkomst. De enkele omstandigheid dat de overeenkomst niet schriftelijk is vastgelegd, doet daaraan niet af. Daartegenover heeft [gedaagde] haar betwisting onvoldoende concreet en feitelijk onderbouwd. De vordering van Code 95 tot betaling van de openstaande facturen ten bedrage van € 5.429,86 is daarom toewijsbaar.

Buitengerechtelijke incassokosten en rente

4.9

Nu [gedaagde] de verschuldigde facturen niet heeft voldaan, verkeert zij in verzuim. De gevorderde wettelijke rente is daarom, nu deze op de wet is gegrond, toewijsbaar vanaf de gevorderde ingangsdatum. Code 95 maakt daarnaast aanspraak op vergoeding van buitengerechtelijke incassokosten. Deze vordering dient te worden beoordeeld aan de hand van artikel 6:96 BW en het Besluit vergoeding voor buitengerechtelijke incassokosten. Nu aan de daarvoor geldende vereisten is voldaan, komen de buitengerechtelijke incassokosten voor vergoeding in aanmerking. Conform het Besluit wordt een bedrag van € 814,48 toegewezen.
